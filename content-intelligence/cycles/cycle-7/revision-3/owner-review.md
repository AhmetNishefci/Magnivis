## Exact narration

How can light reveal an obstacle without being absorbed or reflected by it? Start with one photon and two possible paths that meet again. In this carefully aligned setup, the waves associated with the paths cancel at one output. This detector stays dark. Now block one path with an absorber. Sometimes it absorbs the photon. That trial ends. But in another trial, the dark detector clicks. The photon reached this detector. The obstacle was detected, without absorbing that photon. Why? Blocking one possible path removed the cancellation that kept this detector dark. This is interaction-free measurement, demonstrated in experiments. It succeeds only in some trials. Others absorb the photon, or give no clear answer.
