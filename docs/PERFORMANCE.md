# Published-video performance

Performance snapshots are editorial evidence, not automatic creative commands. Record sufficiently mature data, distinguish raw starts from engaged views, and avoid conclusions from a single upload or the first few hours.

## Video 001 — `earth-to-stars`

Public URL: `https://www.youtube.com/shorts/bvgmCR2Dtcs`

### Initial snapshot — 2026-09-24

YouTube Studio displayed the reporting point as the first 1 day 20 hours.

| Metric | Value |
|---|---:|
| Raw views | 887 |
| Engaged views | 316 |
| Unique viewers | 106 |
| Watch time | 2.1 hours |
| Average view duration | 0:21 of 0:43 |
| Stayed to watch | 36.3% |
| Swiped away | 63.7% |
| Shorts-feed traffic | 91.5% |
| Subscribers gained | 0 |

The retention summary card showed 33.5% stayed-to-watch while the engagement card showed 36.3%, likely because YouTube reports refresh asynchronously. Preserve both rather than inventing false precision.

### Working interpretation

- YouTube provided a real Shorts-feed test; distribution source was not the primary constraint.
- The main weakness was the opening selection rate: roughly two-thirds swiped away.
- Engaged viewers watched about half of the 43-second runtime, with a continuous decline rather than a distinct high-retention payoff.
- The sample is too small for durable geographic or audience conclusions.

### Editorial response in Video 002

- Reduce runtime to 32 seconds.
- Put the core contradiction in frame one.
- Start narration at 0.05 seconds.
- Create a meaningful scale/depth change every few seconds.
- Reach the final quantitative payoff before the last six seconds.

Revisit Video 001 at the seven-day mark and compare future videos against channel baselines rather than generic thresholds.
